Download the zayn command

The zayn command is one file with nothing to install beside it. Download the file for your system and save it as zayn, or zayn.exe on Windows.

Zayn 0.2.0, as published on its release page.

Each file's SHA-256 hash is in SHA256SUMS beside it, and the release notes say how to check one.

chmod +x zayn
./zayn --version

In words: on Linux and macOS the file is marked as a program, then asked its version, and it answers zayn 0.2.0; on Windows, zayn.exe --version answers the same.

A designer can start with nothing installed: the testbench runs the language in the browser ↗.

A first declaration, and its check

A declaration says what a user is doing. Here the user approves a payment, with a way back from every step.

// lawful.zayn
DEFINE INTENT_FLOW approve_payment (
  SATISFIES [SELECT, CONFIRM, ACT],
  ALWAYS_REACHABLE [UNDO, CANCEL]
)

In words: the user selects, confirms and acts, and from every step can cancel or undo. The command finds nothing to refuse, and exits 0.

$ zayn check lawful.zayn
clean — 1 file(s), 0 violations at level 2 against Zayn v3.17

A first refusal, by name and rule

Take the way back out of the same flow, and the command refuses it.

// payments.zayn
DEFINE INTENT_FLOW approve_payment (
  SATISFIES [SELECT, CONFIRM, ACT]
)

In words: the same flow with nothing reachable: the user acts and can neither leave nor take it back.

$ zayn check payments.zayn
payments.zayn:2  error  MISSING_UNDO  approve_payment
    An act declares no way back: SATISFIES holds ACT, ALWAYS_REACHABLE lacks UNDO.
    Rule 79 · The Undo Covenant · Article IV · the right to reverse
payments.zayn:2  error  MISSING_CANCEL  approve_payment
    A flow that acts cannot be abandoned: ALWAYS_REACHABLE lacks CANCEL.
    Rule 26 · The Back Button is Holy · Article IV · the right to leave

2 error(s), 0 warning(s) across 1 file(s) at level 2

In words: the command read line 2, marked in the declaration, and names two refusals, each with its rule and the right it protects. It exits 1.

The step that fails a build

The command exits 0 when every declaration is lawful and 1 when one is refused, so one step in a build is enough.

- name: Check the declarations
  run: zayn check specs/*.zayn

In words: a build step that runs the command over every declaration of the project; a refusal stops the build, and its log names the rule.

Build it from this repository

The same files come from the repository itself, with the compiler zig 0.15.2.

zig build release

In words: run at the repository's root, the release build writes one file for each system into zig-out/release/, and the same build on two machines gives the same files.

This page, declared

This page is a Zayn surface: its visitor comes to discover the command, understand it and find the next step.

// start.zayn
DEFINE SCREEN start (
  SATISFIES [DISCOVER, UNDERSTAND, LOCATE],
  ALWAYS_REACHABLE [EXIT]
)

In words: a visitor discovers, understands and finds their way on, and can always leave. The verifier passes it.

$ zayn check start.zayn
clean — 1 file(s), 0 violations at level 2 against Zayn v3.17
