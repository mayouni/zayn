Each change is checked as you type, and Ctrl+Enter checks at once. A finding's place, such as payments.zayn:2, selects that line in the code. Nothing you type leaves the page.

How the report reads

In the reportWhat it says
the placeThe file and the line the refusal is read at.
error or warningAn error refuses the declaration; a warning names what to look at.
the codeThe violation's name, the same in the zayn command and in its JSON report.
citesWhat the refusal rests on: the rule, then the article and the right it protects.
cleanNothing to refuse at the level chosen.

This page, declared

This page is a Zayn surface: its visitor comes to select an example, edit it and compare the answers.

// testbench.zayn
DEFINE SCREEN testbench (
  SATISFIES [SELECT, COMPARE, UNDERSTAND],
  ALWAYS_REACHABLE [EXIT]
)

In words: a visitor selects, compares and understands, and can always leave. The verifier passes it.

$ zayn check testbench.zayn
