Try · things to run, watch and measure

The tools under Adopt offer three ways to try Zayn without reading the theory first.

These tools gather three ways to run or watch Zayn, so that a person can try it on real pages before reading the theory. It lets a person present Zayn to a team, run the audit on a page, or see what a screenshot can and cannot decide. Each way states what it shows and what it does not.

Three ways to try Zayn, each with what it shows

The tour, a presentation of Zayn in scenes

The tour shows full-screen scenes in an order chosen for the person in the room: a UX designer, a product designer, a programmer, an AI builder or a decision maker.

The tour ↗

The UI audit, which measures a painted page

The UI audit measures what a browser paints on any page that you can serve beside it, and it cites the rule for every finding.

UI audit ↗

The screenshot audit, for an application you do not own

The screenshot audit is for an application that nobody here owns. It reduces a screenshot to facts and judges them on the three rules that a screenshot can decide.

Screenshots ↗

The wasm proof, in the same band, runs the conformance suite through the verifier compiled to WebAssembly in your browser, and the testbench checks a declaration of your own the same way.

The verifier and a local server are one file, zayn (zayn serve, in the binary's design), tested on Windows and Linux and built for macOS. This page is served from inside the file, so the hashes live beside the files, in SHA256SUMS.
