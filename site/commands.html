The commands

One file answers every command. Run it with no argument, or with -h, and it prints how to call check.

The commandWhat it does
zayn check FILE…Checks each declaration against the law and reports each refusal with its rule.
zayn conformanceRuns the conformance suite and its cross-checks in one process.
zayn packWrites the protocol pack's manifest, or with --check verifies it.
zayn cross-medium [SPEC]Renders one declaration on two channels and checks both under one law.
zayn audit-facts [FACTS]Decides the screenshot audit's rules on the facts read from a picture.
zayn serveServes this site, the Reader and the UI audit from inside the file, or another site beside the audit.
zayn site facts|shell|gridRuns this site's own build checks, from the repository's root.
zayn versionPrints the law, the language, the contract and the build it carries; --version prints the release.

The options, command by command

The optionIts commandWhat it does
--level NcheckThe conformance level, from 1 to 4; 2 by default, everything one declaration decides.
--symbols FILEcheckA symbol table in JSON, which the checks of level 3 read; without it they are skipped and say so.
--contract FILEcheckThe list of violations to check against, in place of the one the file carries.
--jsoncheckThe report as JSON, for a program to parse.
--quietcheckThe findings alone, with no summary line.
--level NconformanceThe level of the suite; 4 by default.
--verbose, -vconformance, cross-mediumEach case by name, beside its verdict.
--checkpackVerifies the manifest in place of writing it.
--rules LISTaudit-factsDecides only the rules named, by number, separated by commas.
--root DIRserveServes the site from the folder DIR in place of the copy inside the file.
--app DIRserveServes another site from DIR, read only, with the UI audit beside it.
--port N, --host ADDRserveWhere it listens: the machine itself by default, another address only when --host names it.
--writesiteWrites what the check would compare: the navigation, the tables or the figures.
-h, --helpcheck, siteHow to call the command.

The exit codes a build reads

The codeWhat it means
0Every declaration is lawful, or the suite conforms.
1A declaration is refused, or a case of the suite does not match.
2The command was called wrongly, or a file could not be read.

The JSON report, field by field

With --json, check prints one object. This is a real run on a fixture of the suite, an act with no way back.

$ zayn check conformance/fixtures/missing-undo.zayn --json
{
  "level": 2,
  "contract": {
    "version": "1.11",
    "constitution": "3.17"
  },
  "files": [
    "conformance/fixtures/missing-undo.zayn"
  ],
  "counts": {
    "errors": 1,
    "warnings": 0
  },
  "diagnostics": [
    {
      "code": "MISSING_UNDO",
      "severity": "error",
      "message": "An act declares no way back: SATISFIES holds ACT, ALWAYS_REACHABLE lacks UNDO.",
      "span": {
        "file": "conformance/fixtures/missing-undo.zayn",
        "line": 5
      },
      "cites": [
        "rule:79",
        "article:reversibility",
        "right:reverse"
      ],
      "language": "zayn",
      "level": 2,
      "subject": "post_entry"
    }
  ]
}

In words: one refusal, MISSING_UNDO, on line 5 of the fixture, resting on Rule 79 and the right to reverse; the command exits 1.

The fieldWhat it holds
levelThe level the check ran at.
contract.versionThe version of the list of violations the check used.
contract.constitutionThe version of the law that list belongs to.
filesThe files checked, in the order given.
counts.errors, counts.warningsHow many refusals of each severity; an error makes the exit code 1.
diagnosticsOne entry per refusal, in the order found.
codeThe violation's name, the one a program matches on.
severityerror or warning.
messageThe refusal in one sentence, for a person.
span.file, span.line, span.colWhere the refusal is: the file, the line, and the column when the check knows it.
citesWhat the refusal rests on: the rule first, then the article and the right it protects.
languageThe language the declaration is written in.
levelThe level the refusal belongs to.
subjectThe name of the declaration refused.

This page, declared

This page is a Zayn surface: its visitor comes to locate a command, read its entry and understand its answer.

// commands.zayn
DEFINE SCREEN commands (
  SATISFIES [LOCATE, READ, UNDERSTAND],
  ALWAYS_REACHABLE [EXIT]
)

In words: a visitor locates, reads and understands, and can always leave. The verifier passes it.

$ zayn check commands.zayn
clean — 1 file(s), 0 violations at level 2 against Zayn v3.17
